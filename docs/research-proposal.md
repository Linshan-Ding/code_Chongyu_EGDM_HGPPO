# EGDM-HGPPO 当前研究方案

问题：动态订单下，固定工序专用单元的人机资源重构与并行调度，唯一目标TWT。

主线：动态异质图表达可见需求、异质资源能力及迁移状态；物理事件触发决策，学习门控与图策略选择完整资源迁移方案；派工固定β1 ATC。不使用专家模仿、世界模型或在线前瞻搜索。

保留两个待验证贡献：动态异质图；事件与学习门控共同驱动重构。图／关系共享和周期门控消融必须单独检验贡献；规则先验、PopArt和并行工程为支撑，不另包装创新。本次不开展新颖性检索或预先宣称优于现有研究。

每事件一个联合门控与方案概率，一次奖励／PPO比率。Actor/Critic独立编码优化。初始残差头为零，确定性精确复现β1周期锚点；该一致性不保证训练后改善。DAN单独标为周期资源管理下的学习派工方法。

用户批准1epoch＝同一固定算例的8个并行完整回合＋一次PPO更新周期。仅S/M参与训练，每例100次：联合预实验200epoch／1600回合，正式3600epoch／28800回合。三种子同预算，固定文件不重抽样。取消训练中验证与best选择，统一评测末次模型；训练尾10次均值单列为训练统计。预实验末评使用10个S/M开发实例，正式主测试24个S/M，跨规模测试12个L；XL退出实验。本次只测试和冒烟，长实验由用户后续启动。见[实验规格](experiment-spec.md)及[README](../README.md)。

本仓库不保留早期实验产物，不据此宣称当前方法超过旧β混合策略。当前全部对照及失败结果按既定协议保留。
