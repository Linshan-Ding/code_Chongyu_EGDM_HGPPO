# SM100 实验规格

协议 `paper-sm100-1`；唯一目标 TWT，固定 ATC β=1。保持图、门控、合法候选、PopArt 与 PPO 更新实现。每个 epoch 在一个固定算例上采集 8 个完整随机回合，随后优化 3 遍；物理事件仅记录，不控制预算。

活动数据：pilot S/M=2；validation S/M=10；train S/M=36；main S/M=24；generalization L=12；tiny=8。共92例。原L开发/训练24例及XL12例已删除，清单保留原参数、种子、哈希及删除原因，不由prepare重建。所有待测主测试与L只在正式授权后计算目标值。

预实验每例100次，共200 epoch/1600回合；正式每例100次，共3600 epoch/28800回合。所有7个唯一学习实现、种子0/1/2同预算、同顺序。无图/MLP共用结果。可选pilot-single只为full在S/M分别100 epoch。

训练不创建验证环境，不周期评估，不选best。末次完整提交模型是唯一最终模型。训练尾统计取每例自己的91至100次访问，共80条回合；若任何记录缺失或非法，不计算有效尾均值。均值来自变化策略，不能冒充独立测试证据。

结束评测：预实验使用10例开发评估，正式使用24例主测试+12例L泛化。所有模型集中在同一登记主机依次进行3次新进程确定性回放，TWT与动作轨迹应一致；重复回放不计为更多训练种子。无自动规则回退。

主比较规则Fixed-EDD/Fixed-ATC/Periodic-ATC/RH-MILP/RH-ALNS；附录Opportunity-ATC。学习比较mlp/gat/dan；消融mlp/shared_relation/periodic_gate/no_rule_prior。DAN使用共同周期管理器。ALNS三个算法种子，MILP每调用0.20秒，ALNS每事件40迭代。保留所有强、失败、未完成对照。

正式准入：预实验报告完整；S/M各自开发评估平均逐例gap不高于-5%；对同配置MLP的平均相对改善不低于-1%；三训练种子、同预算、全部可行、三次回放一致。p95约100ms独立裁决。数值通过不自动授权：用户须审阅并显式生成授权记录，绑定协议和完整报告。

分机训练以方法×种子为单位，每台机器内部同步on-policy；不跨机共享优化器。工作进程数可变，8环境和每例预算不可变。训练与最终评测命令分离，独立任务按协议/阶段/方法/种子/运行编号隔离。科学参数、源码与数据哈希统一，路径和本机执行参数单独记录。

矩阵：pilot-single 24作业（6训练+18回放），pilot-joint 92（21训练+63回放+8规则），formal 93（前述92+1微型参考）。训练任务分别总计600/4200/75600 epoch。缺失任务保留，不报告已完成。主测试和L不能用于选模型或挑选运行编号。
